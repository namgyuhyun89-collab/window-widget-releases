교사용 바탕화면 위젯사용 설명서 · 최신 버전 0.1.8 기준

window-widget

교사가 만든, 교사를 위한 윈도우 바탕화면 위젯 · 마지막 고침 2026년 11월 13일

window-widget은 컴퓨터를 켜면 바탕화면 전체가 하나의 교무 수첩이 되는 윈도우용 무료 프로그램이다. 달력·일정·포스트잇·교시 시계·날씨·급식·시간표·수업 도구·바로가기를 한 화면에 모아 보여 준다.

  • 네이버 캘린더와 읽기·쓰기 연동, 구글 캘린더는 보기와 브라우저로 넣기
  • 지금 몇 교시인지, 남은 시간, 다음 수업 반을 바로 보여 주는 교시 시계
  • 타이머·뽑기·모둠·좌석·QR 코드·예약 끄기 등 수업 도구, 분필로 바로 쓰는 칠판
  • 시간표에 맞춰 “자리에 앉으세요”를 말로 알려 주는 음성 안내(선생님 목소리 녹음 가능)
  • 학생 상담·관찰 기록과 나이스 누가기록 옮기기 도우미
  • TV에 띄울 때 개인 메모를 숨기는 수업 모드 (Ctrl+Alt+H)
  • 메모와 명단은 이 컴퓨터에만 암호화해서 저장, 새 버전은 저절로 업데이트

1.설치

1.1.내려받기

아래 주소에서 window-widget-Setup-0.1.8.exe를 받는다. 이 주소는 늘 가장 새 버전 페이지로 열린다.

https://github.com/namgyuhyun89-collab/window-widget-releases/releases/latest
  1. 받은 Setup 파일을 실행한다.
  2. 설치 방식은 나만 사용을 고른다. 이렇게 해야 새 버전이 저절로 설치된다.[1]
  3. 설치가 끝나면 앱이 뜨고, 다음부터는 컴퓨터를 켜면 자동으로 실행된다.

포터블(Portable) 파일은 설치 없이 바로 실행되지만 자동 업데이트가 되지 않는다. 설치가 막힌 컴퓨터에서만 쓴다.

쓸 수 없는 컴퓨터 · 껐다 켜면 초기화되는 PC(복원 프로그램이 있는 PC)에서는 메모와 설정이 사라지므로 쓸 수 없다.

1.2.파란 경고 창이 뜰 때

실행하면 “Windows의 PC 보호” 창이 뜰 수 있다. 개인이 만든 프로그램이라 유료 코드 서명 인증서가 없어서 뜨는 경고다. 추가 정보 → 실행을 누르면 설치된다.

1.3.처음 설정

처음 켜면 설정 마법사가 뜬다. 모든 단계는 건너뛰고 나중에 바꿀 수 있다.

  1. 학교 고르기 · 학교 이름으로 찾아 고르면 날씨 지역도 학교 주소로 저절로 맞춰지고 다음 단계로 넘어간다.
  2. 캘린더 연결 · 네이버·구글 캘린더 (5절)
  3. 교시 시각 · 40분 수업 기본값이 들어 있다. 월~금 공통으로 한 번에 고친다.
  4. 보드에 보일 칸 고르기

마치면 보드의 칸을 하나씩 짚어 주는 사용법 안내가 뜬다. 트레이 아이콘 오른쪽 클릭 → 사용법 다시 보기로 언제든 다시 볼 수 있다.

2.화면 구성

바탕화면 전체에 보드가 깔린다. 왼쪽 띠는 원래 바탕화면 아이콘 자리로 비워 둔다. 칸은 아래 9개이고, 칸마다 오른쪽 위 ×로 끌 수 있다(바로 뜨는 되돌리기로 다시 켬).

3.주요 기능

3.1.달력과 일정

  • 날짜를 두 번 누르면 일정 추가. ‘저장할 캘린더’에서 네이버 캘린더를 고르면 휴대폰 네이버 캘린더에도 바로 들어간다.
  • 구글 캘린더 (브라우저에서 저장)을 고르면 일정이 채워진 구글 캘린더 화면이 열리고, 저장만 누르면 된다.[2]
  • 하루에 일정이 많으면 칸에 들어가는 만큼만 보이고, +N개 더를 누르면 그날 일정이 모두 보인다.
  • 달력 위 ‹ 버튼으로 1년 전 일정까지 돌아볼 수 있다.
  • 학교만 고르면 학사일정(방학·행사·휴업일)이 함께 보인다. 나이스 인증키가 없어도 된다(지난달~6달 뒤, 12시간마다 새로 받음). 키를 넣으면 1년 치를 더 빨리 받는다.
  • 시각이 있는 일정은 시작 10분 전에 줄이 깜빡이고 알림이 뜬다(설정 → 캘린더 연결에서 바꿈).
  • 일정 정리 칸: 이번 주 일정을 눌러 완료 표시, 맨 아래 칸에 오늘 할 일을 적으면 끝낼 때까지 다음 날로 넘어간다.

3.2.포스트잇 메모

  • + 새 메모 또는 Ctrl+Alt+N. 색을 바꾸고, 체크리스트로도 쓴다. 맨 위 제목 칸에 제목을 달 수 있다.
  • 메모 칸 위 − + 로 모든 포스트잇 크기를 60~180%로 바꾸고, 메모 오른쪽 아래 모서리를 끌면 그 메모만 가로·세로 1~4칸으로 키운다.
  • 메모의 ⋯ → 떼어 내기를 누르면 다른 프로그램 위에 떠 있는 메모가 된다. ⇲ 버튼으로 다시 붙인다.
  • 메모를 달력 날짜로 끌어다 놓으면 일정이 된다. “금요일 3시 …”처럼 쓰면 날짜와 시각을 알아서 읽는다.
  • Ctrl+Alt+Q로 어디서든 빠른 메모 입력. 지운 메모는 30일 동안 휴지통에 있다.

3.3.교시 시계와 시간표

  • 교시 시계가 지금 몇 교시인지, 남은 시간, 다음 수업 반·과목을 보여 준다. 수업 시작 전에 알림도 준다.
  • 시간표를 가져오는 곳은 세 가지: 직접 입력 · 나이스(담임, 학년·반 고르기) · 구글 시트(전담 교사용 주간 시간표 시트, 매주 새 탭을 날짜로 찾아 읽음).
  • 교시 시각은 설정 → 시간표에서 월~금 공통으로 고친다. 수요일만 일찍 끝나는 학교는 요일마다 다르게 정하기를 누른다.
  • 시간표 칸을 오른쪽 클릭하면 ‘3단원 2차시’ 같은 차시 메모를 붙인다.
  • 주간학습 안내 폴더(한글·PDF)를 정해 두면 시간표 칸 위 버튼이 이번 주 파일을 바로 연다.

3.5.급식과 날씨

  • 급식은 학교만 고르면 보인다(키가 없으면 그날 것씩, 키를 넣으면 한 달 치를 미리). ‹ › 로 다른 날, ▾ 로 알레르기 정보.
  • 날씨는 인증키 없이 바로 보인다. 지역은 학교 주소로 저절로 맞춰지고, ‘강화’, ‘대구 달서구’처럼 찾아 바꿀 수도 있다.
  • 미세먼지는 에어코리아 서비스키를 넣고 측정소를 고르면 ‘실외 활동 가능’ 여부까지 보여 준다.

3.6.바로가기와 QR 코드

  • 자주 가는 사이트를 수업용 · 업무용 탭으로 나눠 둔다. 전체 탭은 모두 모아 보여 준다. 연필 버튼으로 더하고 고친다.
  • 폴더 바로가기: 추가 창에서 📁 폴더 → 폴더 고르기로 이 컴퓨터의 폴더(학교 NAS 폴더도 됨)를 넣으면, 누를 때 파일 탐색기로 열린다. 두 컴퓨터를 연동한다면 두 컴퓨터 모두 0.1.8 이상으로 업데이트한 뒤에 쓴다.
  • 바로가기를 오른쪽 클릭 → QR 코드로 크게 띄우기를 누르면 교실 TV에 QR이 크게 뜬다.

3.7.수업 모드

교실 TV에 화면을 띄울 때 개인 메모와 일정을 가린다. Ctrl+Alt+H로 켜고 끈다. 켜져 있으면 트레이 아이콘이 빨갛고 보드 위에 ‘수업 모드’ 표시가 뜬다. 설정 → 수업 모드에서 학생에게 보이는 화면(TV 또는 서브 모니터)과 숨길 칸을 고른다. 수업 도구의 큰 창은 학생 화면에 뜬다.

3.8.보드 꾸미기

  • 배경 사진: 매일 바뀌는 풍경 사진, 내 사진 폴더, 또는 지금 바탕화면 그대로(윈도우 배경화면을 바꾸지 않음).
  • 칸 바탕: 투명(유리) 또는 불투명. 투명이어도 칸 맨 위 메뉴 줄은 불투명해서 잘 보인다.
  • 보드 크기: 오른쪽 위 ⤡를 누르면 테두리를 끌어 줄이고 위쪽 띠를 끌어 옮긴다. 남는 자리에는 원래 바탕화면이 보인다.
  • 자유 배치: 설정 → 보드 크기·배치 → 칸 배치 → 자유 배치 후 보드의 배치 편집. 칸을 끌어 옮기고, 노란 모서리로 크기를 바꾸고, 다른 칸 위에 놓으면 탭으로 합쳐진다.

3.9.두 컴퓨터 연동

학교와 집 컴퓨터에서 같은 메모·할 일·차시 메모·바로가기가 보이게 한다. 두 컴퓨터에 구글 드라이브 데스크톱을 같은 계정으로 깔고, 양쪽에서 설정 → 두 컴퓨터 연동 → 연동 켜기를 누른다. 새로 설치한 쪽은 다른 컴퓨터 내용 받기를 고른다. 기본은 꺼져 있다.

3.10.음성 안내

  • 수업 도구 → 📢 음성 안내. 맨 위 음성 안내 켜기를 눌러야 시작한다(처음에는 꺼져 있음).
  • “쉬는 시간 끝나기 1분 전”, “점심시간 끝나기 5분 전”, “마지막 교시 끝날 때(청소)”, “3교시 시작 3분 전(이동 수업)”처럼 시간표에 맞춰 정하거나 08:40 같은 시각으로 정한다. 시간표 시각을 바꾸면 안내도 따라 바뀐다.
  • 정한 때가 되면 딩동댕 뒤에 화면 가운데에 글이 크게 뜨고 소리 내어 읽는다(PPT·동영상 전체 화면 위에도 뜸). ✕로 바로 멈춘다.
  • 목소리: 기계 목소리 · 내 녹음(마이크로 30초까지) · 소리 파일(mp3·wav·m4a, AI 성우 사이트에서 만든 파일도 됨).
  • 주말과 학사일정의 휴업일·방학에는 울리지 않는다. 행사 날은 오늘만 쉬기. 소리 크기는 윈도우 소리·교실 스피커를 따른다.

3.11.학생 기록과 나이스 옮기기

  • 수업 도구 → 🗂️ 학생 기록. 학생을 골라 날짜·종류(상담·관찰·학부모·기타)·영역(교과·행동특성·창체·기타)과 내용을 남긴다.
  • 이 컴퓨터에 암호화해서 두고, 수업 모드에서는 가린다. 백업·연동 파일은 복구 암호로 잠근다.
  • 나이스에 자동으로 넣지는 않는다(나이스는 바깥 프로그램 입력을 허용하지 않는다). 대신 기록마다 글자 수·바이트(한글 3, 영문·숫자 1, 줄바꿈 2)를 보여 주고, 복사 버튼과 나이스에 옮김 표시를 둔다.
  • ⇢ 나이스로 옮기기를 누르면 안 옮긴 기록을 학생 순서대로 한 건씩 크게 보여 준다. 날짜 복사 → 내용 복사 → 나이스에 붙여 넣기 → 옮김 표시하고 다음.

6.업데이트

새 버전은 저절로 설치된다. 버튼을 누를 필요가 없다.

  • 컴퓨터를 켜면 10초 뒤 새 버전을 확인하고, 받으면 알림 뒤 10초쯤 꺼졌다 새 버전으로 켜진다.
  • 낮에 받은 새 버전은 컴퓨터를 15분 넘게 안 쓸 때(쉬는 시간·점심·퇴근 뒤) 설치된다. 시간표의 수업 시간과 수업 모드 중에는 하지 않는다.
  • 업데이트 뒤 처음 켜면 업데이트 안내 창이 새 기능을 알려 준다. 메모와 설정은 그대로다.
  • 바로 받고 싶으면 보드 오른쪽 위 초록색 새 버전 · 지금 업데이트를 누른다.
0.1.0~0.1.2를 쓰는 경우 · 옛 버전은 저절로 설치가 잘 안 된다. 트레이 아이콘 오른쪽 클릭 → 종료 후 다시 켜거나, 설정 → 데이터 → 업데이트 → 지금 확인 → 지금 다시 시작해 적용을 한 번 눌러 준다. 그다음부터는 저절로 된다.

7.개인정보 처리 안내

이 앱에는 개발자 서버가 없다. 선생님의 정보를 모으는 곳이 없어서, 개발자가 정보를 가져가거나 서버에서 한꺼번에 새어 나갈 일이 구조적으로 없다. 사용 통계나 오류 보고도 보내지 않는다.

7.2.복구 암호

설정 → 백업·복구·암호에서 한 번 정한다(8자 이상). 백업·내보내기·연동 파일을 이 암호로 잠근다. 윈도우 비밀번호가 초기화되어 이 컴퓨터의 잠금이 풀리지 않을 때, 새 PC로 옮길 때 이 암호로 되살린다. 잊으면 백업을 열 수 없으니 종이에 적어 둔다. 두 컴퓨터 연동은 양쪽에 같은 암호를 넣는다. 정하기 전에는 보드 오른쪽 위에 ‘🔑 복구 암호 정하기’가 보인다.

7.3.전근·PC 반납할 때

  1. 설정 → 백업·복구·암호 → 전체 내보내기로 내 데이터를 USB에 옮긴다(복구 암호로 잠김).
  2. 같은 화면 맨 아래 내 정보 모두 지우기를 누른다. 메모·명단·일정·비밀번호·백업·연동 파일까지 지우고 처음 상태로 돌아간다.
  3. 네이버 → 내 정보 → 보안 설정 → 애플리케이션 비밀번호에서 이 앱용 비밀번호를 지운다.

7.4.조심할 점

  • 여러 사람이 같은 윈도우 계정을 쓰는 PC에서는 그 계정의 누구나 앱 화면을 볼 수 있다. 이런 PC에서는 네이버 캘린더를 연결하지 않는다(애플리케이션 비밀번호는 네이버 메일에도 쓸 수 있다).
  • 학생 명단을 두 컴퓨터 연동으로 구글 드라이브에 올리기 전에 학교·교육청 지침을 확인한다.
  • 접속하는 곳은 설정 → 정보 → 외부 통신 목록에 모두 적혀 있다.
